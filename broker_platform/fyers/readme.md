How to Generate the token
1. Execute python3 fyers_generate_token.py
2. Script will prompt "Enter config file path:". Provide the complete path of yaml config file
3. Script will provide TOTP value with the prompt "Use this TOTP for login in Web Browser:". Use this totp to login
4. Script will prompt "Enter the URL from redirect URLOpening in existing browser session". Copy the url from chrome and paste the same here.
5. After this config file will be updated with latest access token
